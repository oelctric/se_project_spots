# Spots

## Description

Spots is a responsive photo-sharing profile page that showcases memorable places and a curated gallery of images. It features a clean, BEM-compliant design with smooth transitions and responsive layouts for mobile, tablet, and desktop.

## Technologies & Techniques

- **HTML5**: Semantic structure for accessibility and SEO.
- **CSS3**: BEM methodology, Flexbox, and CSS Grid for styling and layout.
- **Responsive Design**: Breakpoint-based styling to ensure a seamless experience across devices.
- **Accessibility**: Proper alt tags and hover states for all interactive elements.
